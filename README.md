## Features

### HUD
- FPS, CPS, Ping, XYZ, Direction, Keystrokes, Armor, Potions, Combo, Reach
- HUD styling: color, shadow, background + opacity, scale, drag-move editor

### Visuals / Combat
- FullBright, FOV Changer, ToggleSprint
- ClickGUI (RSHIFT): categories, search, sliders, keybind capture, profiles

### Core
- Modules, 9 setting types, JSON config + profiles, per-module keybinds

## Requirements

- Minecraft Java Edition **26.2**
- Fabric Loader **0.19.5**
- Fabric API **0.161.0+26.2**
- Java **25**

## Install

1. Install Fabric Loader
2. Drop the jar into `mods/`
3. Launch Minecraft

## Honest limitations

- In-game verification pending (see checklist in repo).
- Minecraft-version specific.
